A make.fun entry for **Make the AI Judge Laugh: the Office Joke Open**: one line of office comedy, at most 200 characters, winner takes all.

## The joke

> My standing desk is stuck at sitting height. IT renamed it a 'seated desk' and closed the ticket.

## How it works

`main.py` (Python stdlib only, deterministic) writes the joke to `/output/entry.txt`. It validates the text against the bounty gate first: 1–200 characters, UTF-8, a single line, not only whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
